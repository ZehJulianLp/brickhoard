Noch keinen User Token?

BrickHoard kann ihn über den offiziellen Rebrickable-Endpunkt erzeugen. Dein Rebrickable-Passwort wird nur für diese eine Anfrage verwendet und weder gespeichert noch protokolliert.

{{ render_field(form.rebrickable_login) }} {{ render_field(form.rebrickable_password) }} {{ form.generate_token(class='btn btn-outline-dark') }}

Wo finde ich die Werte?

  1. Bei Rebrickable anmelden.
  2. Unter Settings → API einen API-Key erzeugen.
  3. Den persönlichen User Token aus dem API-Bereich übernehmen.

Geheimnisse werden verschlüsselt gespeichert und niemals vollständig im Formular angezeigt.
